# Remove tracked vacancies without erasing applications

Removing a vacancy forgets its tracked vacancy/search history and permits later rediscovery, while preserving independently owned application records. On rediscovery those records link back to the vacancy; their identities must not permanently suppress a deliberately removed vacancy, and retained application history alone must not recreate the removed table row. This favors reversible tracker membership over deleting the candidate's application history or permanently dismissing an opening.
