# Interchangeable subscription-backed AI CLIs

AI interpretation runs through a locally installed CLI chosen per process — Codex or Claude Code — behind one bridge interface (`status`, `guided_profile`, `interpret_batch`, `cache_version`). Python keeps owning prompts, schemas, validation, dialogue state and every write; a bridge only runs one bounded, tool-less, structured-output turn. Each bridge accepts only subscription logins and strips API-key, gateway and cloud-provider variables, so switching provider never silently switches billing. Claude Code on Amazon Bedrock is the one separately billed route, available only as an explicit opt-in (`JSF_CLAUDE_AUTH=bedrock`) for people who already run Claude Code through their AWS account. The selection is explicit (`--ai-provider`/`JSF_AI_PROVIDER`) or the first installed CLI, Codex first, so existing Codex setups behave unchanged. Reusable vacancy facts are keyed by provider, trading one re-extraction after a switch for never mixing interpretations from different models.
